# 超市临期管家 🛒

一个无需后端即可运行的超市商品临期管理网站。

## 功能

- 添加、编辑、删除商品
- 记录类别、条码/SKU、数量、过期日期、货架位置、备注
- 自动计算剩余天数
- 距离过期 ≤ 45 天自动标记为“临期”
- ≤ 15 天标记为“紧急”
- 已过期自动标记
- 首页统计全部、45天内、15天内、已过期商品
- 搜索与状态筛选
- 浏览器通知提醒
- LocalStorage 保存数据
- Service Worker 离线缓存
- 响应式手机/电脑界面

## 使用

直接打开 `index.html` 即可。建议通过 GitHub Pages 部署，这样浏览器通知和 PWA 能力更稳定。

> 当前版本的数据保存在浏览器本地，不同设备/浏览器之间不会自动同步。
